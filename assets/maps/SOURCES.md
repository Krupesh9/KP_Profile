# Map Sources

- USA and India outline geometry: [Natural Earth Vector, Admin 0 Countries, 1:50m](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson), public domain.
- Education location markers use approximate coordinates for Bridgeport, Connecticut and Vallabh Vidyanagar, Gujarat.

The source geometry was simplified for legibility at the small display size. Alaska and Hawaii are presented as labeled insets on the USA map.
